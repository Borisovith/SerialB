Обзор

SerialB — продвинутый монитор последовательного порта с:

  • подсветкой по ключевым словам и числовым диапазонам;
  • триггерами (автостоп при появлении слова);
  • макросами (быстрые команды одной кнопкой);
  • настраиваемыми темами (тёмная/светлая/системная);
  • поиском с подсветкой всех совпадений;
  • мультиязычным интерфейсом (EN/DE/UK/RU).

Конфигурация хранится рядом с приложением в файле config.json. Языки — в папке lang/.

Верхняя панель

Элемент Назначение
Выбор порта: (Combobox) Список доступных COM/tty портов. Обновляется кнопкой 🔄 Обновить.
🔄 Обновить Пересканировать доступные порты и заполнить список заново.
Скорость: (Combobox) Скорость порта. Стандартные значения: 300 … 2000000. По умолчанию — 115200.
🔌 Подключить Открыть порт с выбранной скоростью. Дополнительно: если включён «Сброс при подключении» — плата перезагрузится.
❌ Отключить Закрыть порт. Кнопка неактивна, пока соединения нет.
Индикатор ● Online / Offline Кружок слева от надписи:
● серый — нет соединения;
● зелёный — порт открыт.
☑ Сброс при подключении Если включено — при подключении отправляется импульс DTR/RTS, ESP32 перезагружается. Удобно для мониторинга с самого старта.
☑ Автоподключение Если включено — приложение само подключается к порту, как только он появится в системе. При отключении — ждёт возврата.
Таймаут сбора пакета: (слайдер + поле) Время ожидания данных от порта (в мс). Меньше — быстрее реакция, но больше нагрузка. Больше — реже «пустые» чтения. По умолчанию 50 мс.
Таймаут можно ввести вручную в поле или подкрутить слайдером. Значение сохраняется в config.json и восстанавливается при следующем запуске.

⏱ Время лога: ВКЛ Показывать метку времени [HH:MM:SS.mmm] перед каждой строкой. Кнопка становится зелёной, когда включена.
Δ Интервал: ВЫКЛ Показывать задержку между строками [+NNNms]. Кнопка становится зелёной, когда включена.

M — всего в буфере;

⚙ Быстрый переход в настройки → вкладка «Общие» (там меняется лимит строк).

Область лога

Основное поле вывода. Поддерживает:

  • Подсветку по правилам ключевых слов (синий/красный/жёлтый текст);
  • Подсветку числовых диапазонов (например, значения 2–4 могут быть бирюзовыми);
  • Подсветку интервалов (например, задержка 100–1000 мс — жёлтая);
  • Поиск с подсветкой (жёлтая заливка всех совпадений, оранжевая — активное);
  • Выделение мышью и контекстное меню (правая кнопка → «Копировать выделенное»).

Формат строки

[HH:MM:SS.mmm] [+NNNms] [RX] Текст строки

Метка времени и интервал опциональны — включаются кнопками в боковой панели.

Теги строк

ТегЧто означает
[RX]Данные, полученные от платы.
[TX]Данные, отправленные плате.
[Система]Служебные сообщения приложения (подключение, отключение).
[Триггер]Сработало правило триггера.
[Действие]Пользовательские действия (сброс ESP).
[Ошибка]Ошибка порта или соединения.

Вкладка «⚡ Макросы»

Шесть пар полей: Название + Команда.

ПолеОписание
НазваниеЧто показывать на кнопке макроса в главном окне.
КомандаЧто отправлять в порт при нажатии. Приложение добавляет CRLF автоматически.

Пример:

Название: WiFi Scan Команда: AT+CWLAP

Вкладка «🛑 Триггеры»

Триггер — это «стоп-слово». Как только оно появляется в RX-строке, лог автоматически замораживается (скролл останавливается), а в лог добавляется системное сообщение.

КнопкаДействие
ДобавитьСоздать новое стоп-слово.
ИзменитьОтредактировать выбранный триггер.
УдалитьУдалить выбранный триггер.

Каждая строка списка имеет вид:

✔ [Активно] ➔ guru meditation error

Поля в диалоге триггера

  • Активно — включить/выключить правило без удаления.
  • Стоп-слово (триггер) — текст, при появлении которого сработает правило.

Вкладка «🎨 Ключевые слова»

Правила подсветки текста. Например, «ERROR» → красный, «WARNING» → жёлтый.

Структура правила

ПолеОписание
АктивноВключить/выключить правило.
Слово или фразаЧто искать в строке лога.
Часть словаИскать как подстроку (например, «err» найдёт «error», «errors», «stderr»).
Точное совпадениеИскать как отдельное слово (не «error» в «error_handler», а именно «error»).
Подсветить всю строкуКрасить всю строку целиком.
По границам словаКрасить только само совпадение (или слово вокруг — знак '=' считается частью слова).
Цвет текстаВыбор цвета через палитру.
Если ни одно правило не сработало, применяется подсветка из вкладки «Числовые диапазоны».

Вкладка «📊 Числовые диапазоны»

Красит числа, попадающие в указанный диапазон. Например, значения 2–4 — бирюзовые.

ПолеОписание
От / ДоГраницы диапазона (включительно). Поддерживаются отрицательные и дробные.
Подсветить всю строку / По границам словаКак в правилах ключевых слов.
Цвет подсветкиЦвет для чисел из диапазона.

Строка в списке:

[✔] От 2.0 до 4.0 | Область: по границам слова | Цвет: #4ec9b0

Вкладка «⏱ Интервалы»

Красит метку интервала [+NNNms], если она попадает в указанный диапазон. Работает только когда включён режим «Δ Интервал».

ПолеОписание
От (мс) / До (мс)Границы интервала.
Цвет подсветкиЦвет метки [+NNNms].

Пример: если правило «От 100 до 1000» с цветом #cca700, то при задержке 500 мс метка [+500ms] будет жёлтой.

Вкладка «📋 Общие»

Максимальное число строк в логе

Лимит автоочистки. Когда буфер достигает этого размера, старые строки удаляются при поступлении новых. Минимум — 100, по умолчанию — 5000.

Размер шрифта лога

Слайдер от 6 до 32 pt и поле точного значения (6–48 pt). Изменения применяются сразу, но сохраняются в конфиг при закрытии окна настроек.

Вкладка «🌐 Язык»

Выбор языка интерфейса из доступных (en, de, uk, ru). Язык по умолчанию — английский.

После смены языка требуется перезапуск приложения, чтобы интерфейс обновился. Все языковые файлы лежат в папке lang/ рядом с приложением. Чтобы добавить новый язык — положите туда xx.json по образцу en.json.

Диалоги правил

Каждая вкладка с правилами (Триггеры, Ключевые слова, Числовые диапазоны, Интервалы) открывает свой диалог при нажатии «Добавить» / «Изменить».

ДиалогПоля
Триггер Активно, Стоп-слово.
Ключевое слово Активно, Слово/фраза, Часть/точное совпадение, Область (вся строка / по границам), Цвет текста.
Числовой диапазон Активно, От, До, Область, Цвет.

Внизу каждого диалога — кнопка Сохранить. Отмена — закрытие окна крестиком.

Файлы и настройки

config.json

Создаётся автоматически рядом с приложением при первом сохранении настроек. Хранит:

  • язык интерфейса и тему;
  • последний порт и скорость;
  • флаги: авто-подключение, сброс при подключении, состояния кнопок отображения (RX/TX, время, интервал, стоп-скролл);
  • лимит строк и размер шрифта лога;
  • все правила: триггеры, ключевые слова, диапазоны, интервалы;
  • макросы (имя + команда).

lang/

Папка с языковыми файлами. При первом запуске exe рядом с ним распаковывается en.json — как пример и базовый язык. Остальные языки вшиты внутрь exe и используются, пока файл не появится снаружи.

Приоритет: файл в lang/ рядом с exe перекрывает вшитый. Так можно править переводы без пересборки.

Частые вопросы

Не подключается к плате

  • Проверь, что порт виден в списке (кнопка 🔄 Обновить).
  • Убедись, что порт не занят другой программой (Arduino IDE, PlatformIO, PuTTY).
  • На Linux может понадобиться добавление пользователя в группу dialout:
    sudo usermod -a -G dialout $USER и перелогин.

Кракозябры вместо текста

Проверь скорость (baudrate) — должна совпадать с прошивкой. Для ESP32 обычно 115200 или 921600.

Правило подсветки не срабатывает

  • Убедись, что правило Активно (галочка в диалоге).
  • Проверь режим: «Часть слова» работает как подстрока, «Точное совпадение» — как отдельное слово.
  • Если одновременно подходит несколько правил, применяется первое сработавшее (сверху вниз).

Язык не меняется после выбора

Перезапусти приложение. Мгновенная смена языка не поддерживается — интерфейс строится один раз при старте.

Как сбросить настройки?

Удали config.json рядом с приложением. При следующем запуске он создастся заново со значениями по умолчанию.

Как добавить свой язык?

  1. Скопируй lang/en.json в lang/xx.json (где xx — код языка, например fr).
  2. Переведи значения (не трогай ключи слева от двоеточия).
  3. Измени "lang_name" на название языка.
  4. Перезапусти приложение — язык появится в списке.
