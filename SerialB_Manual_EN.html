Overview

SerialB is an advanced serial port monitor with:

  • highlighting by keywords and numeric ranges;
  • triggers (auto-freeze on a matching word);
  • macros (quick commands on a single button);
  • customizable themes (dark / light / system);
  • search with inline highlighting of all matches;
  • multi-language UI (EN / DE / UK / RU).

Configuration is stored next to the application in config.json. Languages live in the lang/ folder.

Main window

The main window is divided into 5 zones:

Top bar

Element Purpose
Port: (Combobox) List of available COM / tty ports. Refresh with 🔄 Refresh.
🔄 Refresh Re-scan available ports and repopulate the list.
Baud rate: (Combobox) Port speed. Common values: 300 … 2000000. Default is 115200.
🔌 Connect Open the port with the selected baud rate. If «Reset on connect» is enabled, the board will be rebooted.
❌ Disconnect Close the port. Disabled while no connection is active.
Indicator ● Online / Offline Circle to the left of the label:
● grey — disconnected;
● green — port is open.
☑ Reset on connect When enabled, a DTR/RTS pulse is sent on connect and the ESP32 reboots. Useful to catch logs from the very start.
☑ Auto-connect When enabled, the app connects automatically as soon as the port appears. When the port disappears, it waits for it to return.
Packet timeout: (slider + field) Wait time for data from the port (ms). Smaller — faster reaction, more CPU. Larger — fewer empty reads. Default is 50 ms.
Timeout can be typed manually or set with the slider. The value is saved to config.json and restored on the next launch.

Macro bar

Element Purpose
Macro 1..6 Sends a saved command to the port. The label comes from the «Name» field in the macro settings; falls back to Macro N.
⚙ Settings Open the Settings window.

Side panel

Button / checkbox Purpose
⏸ Freeze scroll Freeze the log view: new lines still arrive in the buffer, but the viewport does not scroll. Good for reading without «runaway» text.
☑ Show RX (Input) Show lines received from the device.
☑ Show TX (Output) Show lines sent to the device.
🗑 Clear log Clear the log buffer and the screen completely.
⟳ Reset ESP Hardware reset of the ESP32 via DTR/RTS. Works only while the port is open.
⏱ Timestamp: ON Show a timestamp [HH:MM:SS.mmm] in front of every line. The button turns green when active.
Δ Interval: OFF Show the delay between consecutive lines [+NNNms]. The button turns green when active.
📋 To clipboard Copy the whole log (all buffered lines) to the clipboard.
💾 To .txt file Save the whole log to a text file.
Lines: N / M (max K) Line counter:
N — visible lines (after filtering);
M — total in the buffer;
K — auto-cleanup limit.
⚙ Quick jump to Settings → «General» tab (where the line limit is set).

Log area

Main output field. Supports:

  • Highlighting by keyword rules (blue / red / yellow text);
  • Highlighting of numeric ranges (e.g. values 2–4 may be teal);
  • Highlighting of intervals (e.g. delays 100–1000 ms in yellow);
  • Search with inline highlight (yellow background for all matches, orange for the active one);
  • Mouse selection and a context menu (right-click → «Copy selection»).

Line format

[HH:MM:SS.mmm] [+NNNms] [RX] Log text

Timestamp and interval are optional — toggle them with buttons in the side panel.

Line tags

TagMeaning
[RX]Data received from the board.
[TX]Data sent to the board.
[System]Application-level messages (connect / disconnect).
[Trigger]A trigger rule fired.
[Action]User actions (ESP reset).
[Error]Port or connection error.

Element Purpose

Enter — next match; Shift+Enter — previous match; Esc — clear.

FieldDescription
NameLabel shown on the macro button in the main window.
CommandWhat to send to the port on click. CRLF is appended automatically.

Example:

Tab «🛑 Triggers»

A trigger is a «stop word». As soon as it appears in an RX line, the log is automatically frozen (scrolling stops) and a system message is appended.

ButtonAction
AddCreate a new stop word.
EditEdit the selected trigger.
DeleteDelete the selected trigger.

Each list entry looks like:

✔ [Active] ➔ guru meditation error

Trigger dialog fields

  • Active — enable / disable the rule without deleting it.
  • Stop word (trigger) — the text that fires the rule.

Tab «🎨 Keywords»

Text-highlighting rules. For example, «ERROR» → red, «WARNING» → yellow.

Rule structure

FieldDescription
ActiveEnable / disable the rule.
Word or phraseWhat to look for in a log line.
Part of wordSearch as a substring (e.g. «err» matches «error», «errors», «stderr»).
Exact wordSearch as a whole word (won't match «error» inside «error_handler»).
Highlight whole lineColor the entire line.
Word boundariesColor only the match (or the surrounding word — '=' is treated as part of a word).
Text colorPick a color from the palette.
If no keyword rule fires, highlighting from the «Numeric ranges» tab is applied.

Tab «📊 Numeric ranges»

Colors numbers that fall into a given range. For example, values 2–4 → teal.

FieldDescription
From / ToRange boundaries (inclusive). Negative and fractional numbers are supported.
Highlight whole line / Word boundariesSame as in the keyword rules.
Highlight colorColor for matching numbers.

List entry:

[✔] From 2.0 to 4.0 | Area: word boundaries | Color: #4ec9b0

Tab «⏱ Intervals»

Colors the interval label [+NNNms] when it falls into the specified range. Works only when «Δ Interval» is enabled.

FieldDescription
From (ms) / To (ms)Interval boundaries.
Highlight colorColor of the [+NNNms] label.

Example: rule «From 100 to 1000» with color #cca700 — a delay of 500 ms makes the [+500ms] label yellow.

Tab «📋 General»

Maximum lines in log

Auto-cleanup limit. When the buffer reaches this size, oldest lines are dropped as new ones arrive. Minimum — 100, default — 5000.

Log font size

Slider from 6 to 32 pt plus a field for an exact value (6–48 pt). Applied immediately, saved to the config when the Settings window is closed.

Files & settings

config.json

Created automatically next to the app on the first save. Stores:

  • UI language and theme;
  • last port and baud rate;
  • flags: auto-connect, reset on connect, display toggles (RX/TX, timestamp, interval, freeze scroll);
  • line limit and log font size;
  • all rules: triggers, keywords, numeric ranges, intervals;
  • macros (name + command).

lang/

Folder with language files. On the first launch of the exe, en.json is unpacked next to it as an example and fallback. The other languages are embedded into the exe and used unless a same-named file appears outside.

Priority: a file in lang/ next to the exe overrides the embedded one. So you can edit translations without rebuilding.

FAQ

Can't connect to the board

  • Make sure the port appears in the list (press 🔄 Refresh).
  • Check that the port isn't busy in another program (Arduino IDE, PlatformIO, PuTTY).
  • On Linux you may need to add your user to the dialout group:
    sudo usermod -a -G dialout $USER, then log out and back in.

Garbled text

Check the baud rate — it must match the firmware. For ESP32 it's usually 115200 or 921600.

A highlighting rule doesn't fire

  • Make sure the rule is Active (checkbox in the dialog).
  • Check the mode: «Part of word» works as a substring, «Exact word» — as a whole word.
  • If several rules match, the first matching one wins (top to bottom).

Language doesn't change after selection

Restart the app. Hot language switching is not supported — the UI is built once at startup.

How do I reset settings?

Delete config.json next to the application. It will be recreated with defaults on the next launch.

How do I add my own language?

  1. Copy lang/en.json to lang/xx.json (xx is the language code, e.g. fr).
  2. Translate the values (don't touch the keys on the left of the colon).
  3. Change "lang_name" to the language name.
  4. Restart the app — the language will appear in the list.
